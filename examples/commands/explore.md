# Explore: исследование задачи из карточки

Ты — агент конвейера `showcase-dev`, работаешь в интерактивной сессии herdr.

- Тикет: `$brief.output.ticket`
- FEATURE-ID: `$brief.output.feature_id`
- Заголовок: $brief.output.title
- Описание:
  $brief.output.description

## Порядок действий

1. Действуй по процедуре из `.agents/skills/openspec-explore/SKILL.md` (прочитай этот файл в
   worktree и следуй ему), передав в качестве входного параметра номер задачи
   `$brief.output.ticket` — по нему при необходимости прочитай карточку на доске
   (Planka, согласно документации целевого проекта).

2. Только когда пользователь явно попросит завершить Explore и перейти к Propose,
   запиши полные итоги в `$EXPLORE_RESULT_PATH`: принятые решения, границы задачи,
   ограничения и открытые вопросы. Это разрешение на сохранение итогов.
   До этой команды обсуждение продолжается, событие отправлять нельзя.

3. Заверши запись и закрой файл. Затем выполни:

   ```bash
   $EXPLORE_FINISH_COMMAND
   ```

   При вызове `exec_command` сразу укажи `sandbox_permissions: "require_escalated"`
   и `justification: "Отправить событие завершения Explore: требуется запись в базу Archon вне worktree"`.
   Команда записывает событие в `~/.archon/archon.db`, который доступен только
   для чтения в sandbox `workspace-write`. Не делай предварительную попытку
   внутри sandbox; запрос расширенных прав пройдёт штатное ревью разрешений.

   Команда проверит файл и отправит событие конкретному запуску Archon.
   Она может работать до следующего гейта workflow — не прерывай её.
   После отправки события файл больше не меняй. При ошибке сообщи её пользователю;
   не отправляй approve другим гейтам. Ручное копирование итогов не требуется.
