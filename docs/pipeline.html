Ответ в wait продолжает процесс

Комментарии и changes requested в PR содержат замечания. Следующий проход запускается ответом человека в Archon.

Verify сообщает, человек решает

ready и needs_work показываются на приёмке. Возврат в Apply происходит по rework, а архивация требует отдельного approve.

Повторяется работа по замечаниям

Один Apply выполняет все оставшиеся задачи или исправления. Цикл не означает «одна подзадача — один агент».
